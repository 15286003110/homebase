# 我的收藏夹 - 手机桌面风格 (v1.2)

一个将浏览器书签转换为**手机桌面风格**的纯前端导航主页。支持智能分组、拖拽排序、深色模式、农历时钟及多种个性化设置，所有数据保存在本地浏览器中。

## ✨ 功能特色

- 📑 **智能分组**：导入书签后自动按网站类型分类（视频、社交、购物等11类）
- ⭐ **常用区**：点击越频繁，图标越靠前，支持位置固定和拖拽排序
- 🕒 **农历时钟**：实时显示时间（含秒）、公历日期、农历日期，两行对齐
- 🎨 **智能图标文字**：纯中文取前4字，1‑3字单行；英文数字最多12字符，≤6单行；混合内容按视觉宽度自适应
- 🌓 **全局深色模式**：一键切换，头部、常用区、书签网格全部适配
- 🖱️ **拖拽操作**：拖动图标可调整顺序、移动分组
- ✏️ **右键菜单**：书签/分组均可重命名、删除、添加
- 📐 **布局自定义**：页面宽度、每行图标数、图标大小、图标圆角均可调节
- 🖼️ **背景自定义**：常用区与全局背景独立设置，支持预设颜色、自定义颜色或图片
- 🔍 **多引擎搜索**：支持Bing、百度、360、搜狗、Google，可自定义增删
- 💾 **数据备份**：导出/导入JSON配置文件
- 🌫️ **固定毛玻璃效果**：常用区图标自带毛玻璃质感，视觉层次分明

## 🚀 快速开始

1. **直接打开**：无需服务器，用浏览器打开 `index.html` 即可使用。  
   （推荐 Chrome / Edge / Firefox 最新版）

2. **导入书签**  
   - 在浏览器书签管理器中导出书签为 HTML 文件  
   - 点击页面右上角 **⚙️ 设置** → **📥 导入收藏夹**，选择导出的 HTML 文件

3. **自定义设置**  
   - 修改站点标题：点击左上角文字直接编辑  
   - 调整布局、背景、圆角：在设置面板中修改，即时生效

## 🧩 使用技巧

| 功能 | 操作方式 |
|------|----------|
| 调整图标顺序 | 拖动图标到目标位置 |
| 移动书签到分组 | 拖动图标到顶部分组标签上 |
| 固定常用区图标 | 右键常用区图标 → 固定位置 |
| 从常用区移除 | 右键常用区图标 → 从常用移除 |
| 修改站点标题 | 直接点击左上角文字 |
| 搜索书签/网页 | 输入关键词实时过滤，按回车用选中搜索引擎搜索 |
| 切换深色模式 | 点击 🌓 按钮 |
| 导出/导入配置 | 设置面板 → 📤 导出设置 / 📂 导入设置 |

## 📂 文件说明

- `index.html` — 主页面，包含全部 HTML/CSS/JS 代码，单文件即可运行
- `README.md` — 项目说明

## 💾 数据存储

所有书签、分组、布局及背景设置均保存在浏览器的 `localStorage` 中，不会上传至任何服务器。清除浏览器数据可能导致配置丢失，建议定期通过 **📤 导出设置** 进行备份。
