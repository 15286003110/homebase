# 我的收藏夹 - 手机桌面风格、收藏夹做个人主页

一个将浏览器书签转化为**手机桌面风格**的纯前端导航主页。  
无需后端，单文件运行，支持智能分组、拖拽排序、多引擎搜索、深色模式、农历时钟、WebDAV 多端同步以及完善的移动端/平板适配。

## ✨ 功能特色

- 📑 **智能分组**  
  导入书签后自动按网站类型归类（视频、社交、购物、设计开发等 11 类），并支持手动创建、重命名和删除分组。

- ⭐ **常用区**  
  根据点击次数自动生成常用区，点击越频繁越靠前。支持固定位置、拖拽调序，显示数量与当前网格列数保持一致，始终满行。

- ☁️ **WebDAV 多端同步**  
  支持将书签数据和设置同步到 WebDAV 服务器，实现多设备数据互通。  
  - **自动同步**：数据变更后延迟 2.5 秒自动上传  
  - **打开页面时同步**：静默比对远程时间，仅在远程更新时自动下载，不弹窗打扰  
  - **关闭页面前同步**：退出时自动上传最终状态  
  - **定时同步**：可设置 5/15/30/60 分钟间隔自动备份到云端  
  - **手动操作**：随时一键上传或下载，下载时会智能检测远程数据是否更新，避免覆盖最新本地数据  

- 🔍 **多引擎搜索**  
  内置 Bing、百度、360、搜狗、Google 五个引擎，可在设置面板中自由增删改。搜索框输入关键词实时过滤书签，按回车直接调用选中引擎进行网页搜索。

- 🕒 **农历时钟**  
  顶部实时显示时分秒、公历日期、星期和农历日期，两行对齐，界面友好。

- 🎨 **智能图标文字**  
  自动根据标题生成图标内文字，纯中文取前 4 字，英文数字自适应单行或双行，混合内容按视觉宽度智能拆分。

- 🌓 **深色模式**  
  一键切换，头部、常用区、书签网格、设置面板全部适配深色主题。智能暗色模式下，自动颜色会转为暗色风格，背景图片叠加暗色滤镜。

- 🖱️ **拖拽操作**  
  在网格内拖拽图标可调整书签顺序，拖动图标至分组标签可更改书签分组，常用区也支持拖拽互换。

- ✏️ **右键菜单**  
  书签、常用区图标和分组标签均支持右键菜单，可添加、重命名、删除或固定/取消固定。移动端支持长按唤出菜单，菜单项尺寸大且自动避让屏幕边缘，触控友好。

- 📐 **智能布局**  
  只需拖动"页面宽度"滑块，系统会自动计算最佳的图标列数和大小，始终保持满屏均匀。  
  图标圆角支持从 **0（正方形）到 100（完美圆形）** 连续调节，分组标签圆角同步变化。

- 🖼️ **背景自定义**  
  常用区与全局背景可独立设置，支持预设颜色、自定义取色或上传图片，也可一键清除自定义背景。全局背景更换后，头部和分组区颜色自动同步，避免内容穿透。

- 💾 **数据备份**  
  所有书签和设置保存在浏览器本地。可导出/导入 JSON 配置文件，也可导入浏览器标准 HTML 书签文件。  
  每日首次打开时自动本地备份，保留最近 5 个版本，可在设置中一键恢复或下载。

- 🔄 **自定义图标**  
  每个书签均可单独设置背景颜色或上传自定义图标图片，图标文字自适应大小和换行。

- 🗑️ **回收站**  
  删除的书签会先进入回收站，保留 30 天，期间可随时还原或彻底删除。

- 📊 **数据看板**  
  实时显示书签总数、分组数、回收站数量、存储占用空间，以及最常点击的 Top 5 书签。

- 📱 **全端适配**  
  桌面端保持顶部固定（头部和分组区吸顶），移动端顶部取消固定，滚动更自然。  
  手机、平板与桌面使用相同的自适应算法，列数自动优化，杜绝横向滚动条，设置弹窗在移动端全部垂直排列，触控与视觉体验俱佳。

- 🔄 **恢复默认**  
  一键重置所有布局、引擎、标题、分组别名等设置，**不影响已收藏的书签**。

## 🚀 快速开始

1. **直接运行**  
   用浏览器打开 `index.html` 即可，无需安装任何服务器或依赖。  
   （推荐 Chrome / Edge / Firefox 最新版）

2. **导入书签**  
   - 点击右上角 ⚙️ 设置 → 📥 导入收藏夹，选择从浏览器导出的 HTML 书签文件。  
   - 亦可直接拖放 HTML 书签文件到页面任意位置实现导入。  
   > 💡 浏览器导出书签：Chrome/Edge 按 `Ctrl+Shift+O` 打开书签管理器 → 导出书签。

3. **配置 WebDAV 同步（可选）**  
   - 点击 ⚙️ 设置 → ☁️ WebDAV 同步 → ⚙️ 打开 WebDAV 同步设置  
   - 填写服务器地址、用户名、密码和远程文件路径  
   - 点击"测试连接"确认连通性  
   - 保存后启用自动同步，多设备间数据自动保持一致  
   > 💡 推荐使用自建 WebDAV（如飞牛 NAS）或 Koofr、TeraCloud 等支持 CORS 的服务。坚果云和 123 云盘因 CORS 限制可能需要额外配置 Nginx 代理。

4. **个性化设置**  
   - 修改站点标题：在设置面板中直接修改。  
   - 调整布局、圆角、背景：拖动滑块或选取颜色，即时生效，关闭后自动保存。  
   - 自定义图标名称颜色：在布局设置中打开颜色选择器即可。

## 📱 多端特性

- **手机**：顶部不固定，图标自适应，触控友好。  
- **平板**：图标与列数自动适配，横竖屏均可正常使用。  
- **桌面**：顶部固定吸顶，完整布局，通过"页面宽度"滑块自由调节宽度，列数自动匹配。  
- 窗口缩放或旋转屏幕时，图标列数和常用区自动重新计算，始终保持满行展示。

### 配置示例（飞牛 NAS）
飞牛 NAS 开启 WebDAV 服务 + Nginx CORS 代理 完整方法
1. 在飞牛 NAS 中开启 WebDAV 服务  
2. 部署 Docker Nginx 代理添加 CORS 头  
3. 在书签工具中填写：  
   - 地址：`http://NAS_IP:8083/webdav`  
   - 路径：`/Myadmin/bookmarks.json`

## 💾 数据存储

所有书签、分组、布局和背景设置均保存在浏览器 `localStorage` 中，不会上传至任何第三方服务器。  
WebDAV 同步功能会将加密后的数据上传至您自己配置的 WebDAV 服务器。

建议定期使用 **📤 导出设置** 功能备份配置文件，以防清除浏览器数据导致丢失。
