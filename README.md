# 📑 我的收藏夹 - 手机桌面风格

一个纯前端实现的浏览器书签导航主页，将收藏夹转换成**手机桌面风格的图标网格**，支持智能分组、拖拽排序、背景自定义、暗黑模式等实用功能。

## ✨ 功能特色

- 🏷️ **智能自动分组**：导入书签后自动按网站类型分类（视频、社交、购物、设计开发等 11 类）
- ⭐ **常用区**：点击次数多的书签自动靠前，支持固定位置
- 🎨 **图标文字优化**：纯中文取前 4 字，全英文/数字最多 12 字符，混合类型按视觉宽度截断
- ✏️ **右键菜单**：书签可重命名、删除、添加，分组可添加、重命名、删除
- 📐 **布局自定义**：可调整页面宽度、每行图标数、图标大小
- 🖼️ **背景美化**：预设 9 种颜色、自定义颜色、上传背景图片（常用区和全局独立设置）
- 🌓 **深色/浅色模式**：一键切换，全局生效
- 📥📤 **数据备份**：导出/导入 JSON 配置文件
- 🔍 **多引擎搜索**：支持 Bing、百度、360、搜狗、Google，可自定义增删
- 🖱️ **拖拽排序**：拖动图标调整顺序、移动到分组、从常用区移除

## 🚀 快速开始

### 1. 直接打开（无需服务器）
由于本页面未使用 Bookmarklet 等需要 HTTP 协议的功能，**直接用浏览器打开 `index.html` 文件即可**。

> 💡 推荐使用 Chrome / Edge / Firefox 最新版。

### 2. 导入浏览器书签
1. 在浏览器中按 `Ctrl+Shift+O`（Chrome/Edge）打开书签管理器
2. 点击「导出书签」保存为 HTML 文件
3. 打开主页 → 点击右上角 ⚙️ → **📥 导入收藏夹** → 选择刚才导出的文件

### 3. 日常使用
- 点击图标即可打开对应网站，点击次数会自动累积并影响常用区排序
- 在搜索框中输入关键词可搜索本地书签，按回车可使用选中搜索引擎搜索网络
- 右键图标或分组标签可进行更多操作

## 🧩 使用技巧

| 功能 | 操作方式 |
|------|----------|
| 调整书签顺序 | 拖动图标到目标位置 |
| 移动书签到分组 | 拖动图标到顶部的分组标签上 |
| 固定常用区位置 | 右键常用区图标 → 固定位置 |
| 从常用区移除 | 右键常用区图标 → 从常用移除 |
| 修改站点标题 | 直接点击左上角文字 |
| 自定义背景 | 设置面板中选择预设色、使用颜色选择器或上传图片 |

## 📂 文件说明

- `index.html` —— 主页面，包含全部 HTML/CSS/JS 代码（单文件即可运行）
- `README.md` —— 项目说明

## 💾 数据存储
所有书签、分组、设置均保存在浏览器的 `localStorage` 中，不会上传到任何服务器。清除浏览器数据会导致配置丢失，建议定期通过 ⚙️ → **📤 导出设置** 备份。
