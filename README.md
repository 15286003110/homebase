我的收藏夹 - 手机桌面风格 功能简介与使用说明
简介
这是一个将浏览器书签转换成手机桌面风格的网页工具。它能自动根据网站内容将书签分类，并以彩色图标网格的形式展示。支持拖拽排序、手动分组、背景美化、搜索引擎切换等实用功能，所有数据自动保存在浏览器本地，无需注册和登录。

主要功能一览
🏷️ 智能自动分组：导入书签后自动识别网站类型（视频、社交、购物、设计开发等11种），也可手动添加自定义分组。

⭐ 常用区：点击越频繁的书签越靠前显示，并支持固定位置。

🎨 图标生成：取书签标题的前4个汉字作为图标文字，4字分两行居中，3字及以下单行，背景色由网站域名决定。

🔍 多引擎搜索：支持 Bing、百度、360、搜狗、Google，可自行增删搜索引擎。

✏️ 右键操作：在图标上点击右键即可重命名、删除，在分组标签上右键可添加/重命名/删除分组。

📐 布局自定义：可调整页面宽度、每行图标数量、图标大小。

🖼️ 背景自定义：常用区和全局背景支持 9 种预设颜色 + 自定义颜色 + 上传背景图片。

💾 数据备份与恢复：所有书签、分组、设置可导出为 JSON 文件，随时恢复。

🌓 深色/浅色模式：一键切换。
使用说明

修改站点标题
点击页面左上角的 “我的收藏夹” 文字，在弹出的输入框中输入新标题，回车即可。页面标签栏的标题也会同步更新。

导入浏览器书签
点击右上角的 ⚙️ 设置 按钮。

在设置面板中点击 📥 导入收藏夹。

选择从浏览器导出的 .html 书签文件（Chrome/Edge：书签管理器 → 导出书签）。

导入后，书签会自动分类并展示在页面中。

浏览与打开书签
切换分组：点击顶部的分类标签（如“视频”“社交”等），下方网格将显示该分组下的书签。
打开网站：直接点击书签图标，即可在新标签页中打开对应网站。点击次数会影响常用区的排序。

搜索书签与网页
搜索本地书签：在顶部搜索框中输入关键词，当前分组下的书签会实时过滤。
网页搜索：输入关键词后，直接按 回车键，会使用当前选中的搜索引擎（默认为 Bing）进行搜索。可通过搜索框右侧的下拉菜单切换搜索引擎。

拖拽操作
调整书签顺序：在下面的书签网格中，直接用鼠标拖拽图标到目标位置，即可改变显示顺序。
移动书签到其他分组：拖拽书签图标到上方的分组标签上，即可将该书签移动到目标分组。

常用区排序：在常用区中拖拽图标可交换位置；已固定的图标需先取消固定才能被点击次数影响。

右键菜单
书签图标右键：弹出菜单，可 添加新书签、重命名当前书签、删除当前书签。
分组标签右键：弹出菜单，可 添加新分组、重命名分组（仅非系统内置分组）、删除分组（自定义分组可删，系统分组不可删）。

常用区图标右键：额外提供 固定位置 / 取消固定、从常用区移除 选项。

分组管理
系统内置分组：视频、社交、购物、设计开发、新闻资讯、教育、工具、音乐、阅读、游戏、生活旅行，共 11 类，不可删除，但可重命名。
自定义分组：通过右键分组标签 → 添加分组，可创建新分组。自定义分组可以重命名和删除。

常用区
只有被点击过的书签才会出现在常用区。
点击次数越多，位置越靠前（固定项除外）。

固定位置：在常用区图标上右键 → 固定位置，该书签将固定在当前位置，不再受点击次数影响；取消固定后恢复动态排序。

从常用移除：右键 → 从常用移除，该书签的点击计数将归零，从常用区消失。

设置面板
点击右上角 ⚙️ 设置 按钮打开设置面板，可进行以下调整：
基础设置
站点标题：修改左上角显示的标题文字。

管理搜索引擎：添加或删除搜索选项（名称 + 搜索URL，需包含 {query} 占位符）。

导入/导出/导入设置：数据备份与恢复。

布局设置
页面宽度：调整整体内容宽度（默认 1200px）。

每行图标数：控制网格列数（默认 9，范围 4~14）。

图标大小：调整每个图标容器的尺寸（默认 72px）。

背景设置
常用区背景：可点击预设色块快速更换，或使用自定义颜色选择器，也可上传本地图片作为背景。点击“清除自定义图”可恢复默认。

全局背景：操作同上，会影响整个网页的背景。

所有设置关闭面板后立即生效，并自动保存。

数据导出与导入
导出设置：在设置面板中点击 📤 导出设置，会下载一个包含所有书签、分组、布局、背景配置的 JSON 文件。
导入设置：点击 📂 导入设置，选择一个之前导出的 JSON 文件，即可恢复所有数据（会覆盖当前数据）。

也可直接拖放 JSON 文件到页面任意位置导入。

深色/浅色模式
点击搜索框旁的 🌓 按钮，即可在深色主题和浅色主题之间切换。系统也会跟随浏览器或操作系统的偏好自动设置初始主题。
小贴士
四字图标显示：如果书签标题只有 3 个字，会直接居中显示；4 个字会等分两行（每行 2 字）；超过 4 个字只取前 4 个字。

自动分组规则：网站域名或标题中包含对应的中文/英文关键词（如“bilibili”“微博”“github”）即被归入相应分类，未匹配的归入“工具”分类。

拖拽分组：可以直接把普通书签拖到分组标签上来改变它的分组；系统内置分组的书签也可以拖到自定义分组。

搜索引擎自定义：在管理搜索引擎界面，可以添加其他搜索引擎，例如：名称“搜狗”，URL https://www.sogou.com/web?query={query}。
